2026 · Applied AI in production

Three production AI and automation systems, built end to end

Built for an IT and cybersecurity distributor on Zoho, Google Cloud and Firebase, these systems pair LLMs (Claude, Gemini) with deterministic checks for finance and procurement teams. I designed and built all three, and all three are live.

Zoho CRM

AI procurement reconciliation

Cross-checks each Zoho quote against the partner PO and the vendor quote, then attaches a clearance report to the quote. Gemini on Vertex AI extracts the PDFs, Claude reconciles them with structured output, and deterministic Python guardrails keep the result exact: blank data means “needs review”, never a mismatch. About 1 minute per analysis; handles quotes of 100+ line items.

  • Claude
  • Gemini
  • Python
  • Zoho widgets
Zoho Books

Bank statement automation

Handles hundreds of bank transactions a month for a multi-entity group. Rules held in Zoho categorise each transaction, then the system posts journals, expenses and vendor payments, consolidates bank charges, attaches supporting documents, supports undo and runs month-end reconciliation. Run from Zoho Books widgets on a Cloud Run backend.

  • Python
  • Cloud Run
  • Gemini
  • Zoho widgets
Zoho Analytics

Budgeting & FP&A platform

Replaced a 12+ sheet Excel process with one data model behind budgets, actuals, forecasts, scenarios, HR cost planning and cash flow, with live Zoho Analytics actuals and a Gemini analyst chatbot. The app is live, and I designed a unit-tested period model for the move to an April–March financial year.

  • React
  • Firebase
  • Gemini
  • Zoho Analytics
